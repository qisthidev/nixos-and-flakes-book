# Instalasi

Nix dapat diinstal dengan berbagai cara:

1. Sebagai package manager di macOS, Linux, atau WSL.
2. Sebagai pengelola lingkungan sistem di NixOS, distribusi Linux yang menggunakan Nix untuk manajemen sistem.

Buku ini terutama berfokus pada penggunaan NixOS dan Flakes. Oleh karena itu, kita akan melewatkan konten yang hanya berkaitan dengan Nix (seperti instalasi di macOS, Linux, atau WSL).

Proses instalasi NixOS cukup mudah, tetapi kita tidak akan membahas spesifiknya di sini. Untuk informasi lebih lanjut, silakan kunjungi situs download resmi di <https://nixos.org/download.html>.

> Jika Anda menggunakan macOS, [ryan4yin/nix-darwin-kickstarter](https://github.com/ryan4yin/nix-darwin-kickstarter) mungkin merupakan titik awal yang baik untuk Anda, Anda dapat belajar cara menggunakan Nix dengan buku ini dan mengambil nix-darwin-kickstarter sebagai titik awal untuk membangun konfigurasi Nix Anda sendiri.
